# Problem No: 3190. Find Minimum Operations to Make All Elements Divisible by Three(Easy)

**Link:** [CLick here](https://leetcode.com/problems/find-minimum-operations-to-make-all-elements-divisible-by-three/description/)

```cpp
class Solution {
public:
    int minimumOperations(vector<int>& nums) {
        int ans = 0;

        for (auto num : nums) {
            if (num % 3 != 0)
                ans++;
        }
        return ans;
    }
};
