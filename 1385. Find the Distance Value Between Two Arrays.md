# Problem No: 1385. Find the Distance Value Between Two Arrays(Easy)

**Link:** [Click here](https://leetcode.com/problems/find-the-distance-value-between-two-arrays/description/?envType=daily-question&envId=2026-11-05)

```py
class Solution:
    def findTheDistanceValue(self, arr1, arr2, d):
        ans = 0

        for i in arr1:
            valid = True

            for j in arr2:
                if abs(i - j) <= d:
                    valid = False
                    break

            if valid:
                ans += 1

        return ans
